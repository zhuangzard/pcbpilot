# 配方：高压 / 低压分区与隔离

目的：让引擎正确识别电压域和隔离器件，布局时把高压器件、低压器件分在隔离带两侧，
并给出爬电距离、电气间隙与开槽建议。**安规距离由人最终确认**——引擎给的是工程默认值。

## 1. 让原理图“说清楚”电压域（引擎靠这些识别）

| 需要 | 原理图里的写法 | 引擎规则 |
|---|---|---|
| 每个隔离侧有自己的地 | 地网分开命名：`GND`（低压）、`GND_ISO` / `PGND_HV`（隔离侧） | 每个地网 = 一个电压域；以 0 Ω / 磁珠相连的两个地合并为一个域 |
| 市电侧可被识别 | 市电网名用 `AC_L` / `AC_N` / `L_IN` / `N_IN` / `LINE` / `NEUTRAL` / `MAINS` / `220V` / `VAC` / `L` / `N` / `PE` | 这些网 → `MAINS` 域，峰值按 325 V（230 Vrms）计 |
| 直流高压可被识别 | 网名带电压：`VIN_100V`、`DC400V`（注意：含 `VBUS` 的网名一律按 5 V 推断），或在 `power.json` 的 `rails[].voltage` 直接声明 | 电压 > 60 V 的域为危险域。`HV_*`、`+HV` 这类名字**不**代表市电或危险电压：板载高压 DC-DC 的输入网常叫 `HV_N5`（5 V），±24 V 脉冲轨常叫 `+HV`——按电压值判断，必要时在 `power.json` 声明 |
| 跨隔离的器件被认出 | 型号字段填真实料号：光耦 `PC817`/`EL3H7`/`TLP*`、数字隔离 `ISO77*`/`ADuM*`/`Si86*`/`CA-IS*`/`π1*`、隔离电源 `B0505S`/`IB05*`/`HLK-*`、变压器位号 `T*`、继电器 `K*` | 这些器件是“桥”，不归入任一域，布局时骑跨隔离带 |

先跑分析，确认域划分正确再往下：

```bash
pcbpilot pcb auto analyze --board board.json --json > a.json
```

在 `circuit.domains` 看每个域的器件与 `hazardous`；在 `circuit.barriers` 看屏障、桥接器件与距离。
器件被分错域时，**修原理图的网名或料号**，不要在 `mech.json` 里硬塞。

## 2. 绝缘等级与距离（引擎默认规则）

| 两侧 | 等级 | 250 V 时爬电 / 间隙 |
|---|---|---|
| 危险电压 ↔ 可触及的 SELV | 加强 reinforced | 5.0 mm / 4.0 mm |
| 危险 ↔ 危险 | 基本 basic | 2.5 mm / 2.0 mm |
| SELV ↔ SELV（为抗干扰或断地环） | 功能 functional | 基本值的一半，最小 0.13 mm |

按 IEC 60664-1 / 62368-1 的污染等级 2、材料组 III、海拔 ≤2000 m 取值，工作电压之间线性插值。
医疗（60601）、家电（60335）、户外/高海拔/污染等级 3 都要**更大**，必须按产品标准重新确定并在
`mech.json` 的 `zones` 手工给出足够宽的分区，或在报告里标注未满足。

## 3. 布局里发生了什么

- 两个电压域按接口位置左右排列（固定接口所在侧决定顺序；无固定件时危险域放左），按器件面积
  分宽度，中间留出**等于爬电距离**的隔离带，并生成全层禁铜禁过孔区（`isolation A|B`）。
- 非桥接器件只能在自己域的分区里；桥接器件中心落在隔离带内，两排焊盘分居两侧。
- 桥接器件自身焊盘排距小于爬电距离时，报告给出“在本体下开 ≥1 mm 槽”的建议（槽让沿面距离
  绕行）。开槽用 `pcbpilot pcb slot --help` 查看参数后执行；当前不会自动写入剧本。

## 4. 核对

```bash
pcbpilot pcb auto run --board board.json --mech mech.json --place --out-dir out/
```

- 报告第 3 节：屏障等级、距离与桥接器件是否符合你的判断；第 4 节 `越出电压域分区 = 0`。
- `preview.svg`：危险域器件为红色；橙色虚线为隔离带；没有任何走线或过孔穿过隔离带。
- apply 后用 `pcbpilot pcb drc` 与 `pcbpilot pcb check` 回读；隔离带在 EasyEDA 中是禁止区域，
  原生 DRC 会报告穿越。

## 常见错误

- 两侧共用同一个 `GND` 网名 → 引擎看到一个域，不会分区（这通常也是原理图错误）。
- 光耦型号字段写成 “光耦” 或留空 → 不被识别为桥，被当作普通 IC 归入某一侧。
- 把 Y 电容当作普通电容 → 它确实跨接两域，应放在隔离带附近并单独核对其额定值；当前引擎
  不专门识别 Y 电容（planned）。
