参与：Claude 主持（先封存意见）、Claude agent（Opus，带实测脚本）、Fable、Kimi。四方拿同一份
[brief](raw/brief.md)，互不可见。原文见 `raw/`，实测脚本见 `raw/scripts/`。状态：**Phase A（只度量、只报告）已实现**——`pcbpilot pcb aesthetics`、`joint.aesthetics`（权重 0），基线、对账与 tidy / USB 差分调查见 [baseline.md](baseline.md)；Phase B 起的生成改动仍待用户确认。

## 1. 现状实测（ESP32 样例板 `esp32-v05-fixed.routed.json`，246 段 / 82 连接）

| 指标 | 实测 | 根因（代码位置） |
|---|---|---|
| 非 8 向线段 | 总长 17.6%（Fable 按段数统计 33%），**全部在焊盘端** | `post.go stringPull` 允许首末段任意角；`plane.go placeFanoutViasChecked` 选扇出过孔只按距离，不看角度 |
| 最刺眼的“微歪” | 24 段只偏 0.5–3° | 同上 |
| 焊盘入线 | 沿轴 36% / 45° 22% / 斜入 42%；26 处从焊盘角出线 | `router.access()` 只按离中心距离选接入点 |
| S 形小错位 | 9 处，偏移 ≈ 1 个路由格（3.196 mil） | `stringPull` 消不掉亚线宽 jog |
| 过孔 | 69 个 / 30 器件（≈1.7/连接） | `ViaCostMil` 默认 60，偏便宜 |
| 落格 | 过孔 0/69、顶点 0/492 在 5 mil 格 | 路由格 3.196 mil 与 5 mil 设计格不整除 |
| 转折 | 全 45°，4.68/in；90° 残留 0 | 主干已干净 |
| 正样本 | **仓库无任何“好的已布线”参考板铜皮** | 布线美观目前无法校准 |

附带电气疑点（与美观无关，需单独查）：USB_DP/DM 并行间距 22 mil，DM 有段换到 BOTTOM 而 DP 全程 TOP——差分对规划可能未生效。

## 2. 共识

1. **先度量、后生成**：先上美观指标（先只报告）+ 负对照/单调性测试，校准后再改路由代价。
2. **新增第 4 组 `aesthetics` 进 joint**，权重 0.10（Fable 0.15），组间保持几何平均，组内算术平均；**不进交付门槛**。
3. **防刷分**：未布通连接按 0 计入；“删一根网 overall 不能升”作为属性测试；任何美化 pass 使电气子分/DRC/过孔数/完成率变差即回滚。
4. **电气豁免硬编码**：蛇形等长、差分、RF 馈线、电源过孔阵列、EMI 开槽、隔离带不计美观罚分。
5. **不换路由引擎**：grid A* + post pass 足够；rubber-band 不值。
6. **VLM 看图只做离线副信号**（A/B 成对偏好 → Bradley–Terry 拟合权重），永不进运行时分数；其指出的问题必须落成几何指标。
7. 仓库已有 `pcb.beautify`（倒弧/泪滴/DRC 修复）typed action，未接入自动流程（Kimi 发现）。

## 4. 器件布局美观（用户补充 2026-09-28：与布线同等重要，含对称性）

现状：`placer.tidy()` 只做 5 mil 吸栅、同组朝向多数派、对称无源件 180° 折叠；layout-score 的 tidy 维只报不修、权重 0.5；
**全仓没有对称检测**（无同构子电路识别、无镜像摆放、无对称度指标）。样例板 `tidy` 实测未生效（原点落格 16/30、电阻 180/270 混用）。

| ID | 布局美观指标 | 几何定义 | 生成手段 |
|---|---|---|---|
| P1 | 行列共线 | 同组/同类器件中心 x、y 1D 聚类（eps 15 mil），不在 ≥2 成员线上的比例 | 对齐线吸附 legalisation（最小位移，复用 placer `try()` 接受/回退） |
| P2 | 阵列等距 | 同行 ≥3 件步距 CV | 固定首尾均分 |
| P3 | 朝向一致 | 同组/同类旋转多数派占比；极性件单独统计 | 组内投票统一（极性件按电流方向） |
| P4 | **对称性** | 同构子电路（型号多重集 + 引脚-网连通模式哈希，如双路 LDO、多路按键/LED、差分 P/N 链、IC 两侧去耦）；镜像误差 = mean‖p − mirror(p')‖ / 模块跨度；旋转也须镜像对应 | 识别后先摆一份，另一份按对称轴镜像作为种子 + `symmCost` 软约束；对称轴取板/模块中线或 IC 中心线 |
| P5 | 模块矩形度 | 功能块凸包面积 / 成员 bbox 并集 | 块内紧凑化 |
| P6 | 边距一致 | 沿板边器件到边距离 CV | 边缘器件对齐同一条边距线 |
| P7 | 留白均匀 | 板面占用密度方差（空一块挤一块） | 块间距均分 |
| P8 | 位号/丝印 | 位号同侧、同阅读方向、字号一致、不压焊盘/过孔/板边 | 统一方位执行器（现 `silk-align` 只避碰） |
| P9 | 落格 | 器件原点落 5/25 mil 格比例 | 输出前吸附 |

电气优先：去耦贴 IC 引脚、热环路最小、隔离带、RF/天线净空、接口朝外 > 对称/对齐；对齐/对称只在 tether slack 内移动，任何电气子分变差即回退。

## 5. 分阶段计划（布局与布线两条线并行；每阶段都跑完整质量矩阵：单测 + 全流程离线链 + 低压→高压/高速压力 + 5 板 fixture bench）

**A. 度量（只报告）**
- 布局：P1–P9 + 对称检测器（输出识别到的同构组、对称轴、镜像误差）。
- 布线：非 8 向占比、焊盘入线、S-jog、转折密度、层方向、平行等距 CV、过孔/顶点落格、单网最大绕行、stub。
- 合成劣化 fixture 单调性测试；5 块真板 + ESP32 样例出基线；补采真板铜皮正样本接入 `layout-calibrate`。

**B. 最便宜的观感修复**
- 布局：查清并修好 `tidy` 未生效；落格；朝向统一；行列对齐吸附 + 阵列等距。
- 布线：扇出线射线化（非 8 向 17.6%→≤2%）；`access()` 轴线优先（轴向+45° 58%→≥90%，角部出线 26→≤3）；S-jog 消除（9→0）；路由格对齐设计格。

**C. 对称 + 计分**
- 对称：同构组镜像摆放（种子 + symmCost）→ 对称组的走线镜像复制/对称代价。
- 计分：aesthetics 组（布局+布线子项）0.10 进 joint，防刷分属性测试；layout-score tidy 维扩为 P1–P9。
- 路由代价：jog 惩罚、过孔代价按层数（受 fixture bench 约束）。

**D. 结构美观**：总线识别 + 等距梳理/通道居中；过孔成行；模块矩形度与留白均匀；位号统一方位执行器。

**E. 人审校准**：A/B 偏好采集（布局图 + 布线图）+ 离线 VLM 初筛 → 权重拟合（Kendall τ ≥ 0.6）；`pcb.beautify` 可选收尾。

每项验收：目标指标改善；电气组分数不降；DRC 0 新增；fixture bench 完成率不降；save→reload 回读一致。
