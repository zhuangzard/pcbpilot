## 1. 现状实测（ESP32 样例板 `esp32-v05-fixed.routed.json`，246 段 / 82 连接）

| 指标 | 实测 | 根因（代码位置） |
|---|---|---|
| 非 8 向线段 | 总长 17.6%（Fable 按段数统计 33%），**全部在焊盘端** | `post.go stringPull` 允许首末段任意角；`plane.go placeFanoutViasChecked` 选扇出过孔只按距离，不看角度 |

## 2. 共识

1. **先度量、后生成**：先上美观指标（先只报告）+ 负对照/单调性测试，校准后再改路由代价。
2. **新增第 4 组 `aesthetics` 进 joint**，权重 0.10（Fable 0.15），组间保持几何平均，组内算术平均；**不进交付门槛**。
3. **防刷分**：未布通连接按 0 计入；“删一根网 overall 不能升”作为属性测试；任何美化 pass 使电气子分/DRC/过孔数/完成率变差即回滚。
4. **电气豁免硬编码**：蛇形等长、差分、RF 馈线、电源过孔阵列、EMI 开槽、隔离带不计美观罚分。
5. **不换路由引擎**：grid A* + post pass 足够；rubber-band 不值。
6. **VLM 看图只做离线副信号**（A/B 成对偏好 → Bradley–Terry 拟合权重），永不进运行时分数；其指出的问题必须落成几何指标。
7. 仓库已有 `pcb.beautify`（倒弧/泪滴/DRC 修复）typed action，未接入自动流程（Kimi 发现）。

## 4. 分阶段计划（每阶段都跑完整质量矩阵：单测 + 全流程离线链 + 低压→高压/高速压力 + 5 板 fixture bench）

**A. 度量（只报告）**
- `pkg/pcbauto/aesthetics.go`：非 8 向占比、焊盘入线、S-jog、转折密度、层方向、平行等距 CV、过孔/顶点落格、单网最大绕行、stub。
- 合成劣化 fixture 单调性测试；补采真板铜皮正样本接入 `layout-calibrate`。

**B. 最便宜的观感修复**
1. 扇出线射线化：过孔只放在焊盘中心 8 向射线上（目标非 8 向 17.6%→≤2%）。
2. `access()` 按焊盘轴线优先（轴向+45° 58%→≥90%，角部出线 26→≤3）。
3. S-jog 消除（9→0）、线宽子段共线合并。
4. 路由格取设计格约数或输出前 ≤1 格吸附（落格率→≥90%）。

**C. 计分 + 代价**
- aesthetics 组 0.10 进 joint（含防刷分属性测试）；A* 加 jog 惩罚、过孔代价按层数（受 fixture bench 约束）。

**D. 结构美观**
- 布局对齐线吸附 + 阵列等距（先查清 `placer.tidy` 为何在样例中未生效）；总线识别 + 等距梳理/通道居中；过孔成行。

**E. 对称与人审校准**
- 同构通道检测与镜像摆放/走线；A/B 偏好采集工具 + 离线 VLM 初筛 → 权重拟合（目标 Kendall τ ≥ 0.6）；`pcb.beautify` 可选收尾。

每项验收：目标指标改善；电气组分数不降；DRC 0 新增；fixture bench 完成率不降；save→reload 回读一致。
