# Claude 独立意见（写于看到 Fable / Kimi 结果之前）

## 1. 美观指标（全部基于几何可算）
布线：
- R1 转折密度：每英寸非焊盘端转折数；目标 ≤ 0.5/in，ramp 0.5→3。
- R2 锐角/直角残留：非 45°倍数段、90° 角、<135° 内角个数（除焊盘 stub）；0 为满分。
- R3 锯齿/小折返（jog）：长度 < 3×线宽的中间段、S 形 dogleg；0 为满分。
- R4 层方向纪律：内/底层 H/V 主方向一致率（按长度加权），目标 ≥ 80%。
- R5 平行总线梳理：同组（总线/同源同宿）并行段间距变异系数 CV，目标 < 0.15；并行段断续数。
- R6 焊盘入线质量：沿焊盘长轴进入、入线点居中、线宽 ≤ 焊盘宽；违例计数。
- R7 过孔整齐：过孔落格率、同组过孔对齐成行率、过孔-焊盘距离一致性。
- R8 走线绕行比（已有 detour）与“拥挤不均”：通道利用率方差（线挤在一边、另一边空）。
- R9 线宽一致：同网同类段线宽种类数、无意义 neck。
- R10 对称：差分对/镜像通道的几何对称误差（镜像后 Hausdorff 距离）。
布局：已有 tidy 五项 + 行列对齐率（中心共线簇）、相同子电路镜像/复制一致性、块内朝向统一、留白均匀度。
铜/丝印：铺铜碎岛/尖角数、丝印与焊盘/板边冲突、位号方位一致。

## 2. 计分
- joint 新增第 4 组 “aesthetics”，权重 0.15，从 efficiency 和 placement 各匀出一部分：electrical 0.45 / efficiency 0.18 / placement 0.22 / aesthetics 0.15。几何平均保留。
- 防作弊：美观只在“已布通的网”上计，且乘 completion 因子；未布通网不贡献满分。
- 电气优先规则：凡是电气规则要求的形状（蛇形等长、差分耦合、热环路最短、隔离槽/带、电流颈缩）从美观罚分中豁免（按段标签 reason 标注）。
- 校准：黄金板 + 负对照 + 人工成对偏好（A/B 截图让用户选），用 Bradley–Terry 拟合权重。

## 3. 生成（布局）
- 放置后“对齐合法化”pass：同组器件中心按 x/y 聚类到共线（容差 ≤ 15 mil），LP 最小位移且不违反间距；同类阵列等距；朝向按组投票统一；重复通道检测（同构子图）→ 复制相对坐标。

## 4. 生成（布线）
- A* 代价：层方向偏好（逆主方向 ×1.5）、转折（已有）、与相邻同组线平行的奖励、过孔落格。
- 布线后美化 pass（各自前后跑 DRC/电气校验，失败回退）：jog 消除 → 拉直 → 总线梳理（等间距重排）→ 焊盘入线整形 → 统一 45° 斜切长度 → 过孔对齐 → 泪滴（可选）。
- 顺序：先电气关键网，再总线整组布，再其他；为美观局部 rip-up 只在不降低电气分时接受。

## 5. VLM 视觉评审
- 可作辅助：渲染 SVG→PNG，让模型指出“看着乱”的区域 → 必须映射回具体几何指标或新增指标；不直接进分数。

## 6. 优先级
1 R2/R3 检测+清理（最便宜、最显眼） 2 R1 转折密度+代价 3 R4 层方向 4 R6 焊盘入线 5 R5 总线梳理 6 布局对齐合法化 7 aesthetics 组进 joint + 校准 8 R7 过孔对齐 9 对称 10 VLM 评审。
验收：5 块 fixture before/after 各指标改善，电气组分数不降，DRC 0 新增，fixture bench 布通率不降。
