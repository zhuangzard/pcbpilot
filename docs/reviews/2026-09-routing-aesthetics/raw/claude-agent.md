# PCB 布局/布线美观度：评分与生成（独立评审 · claude-agent）

> 代码只读取自 `/Users/taisen/Documents/Github/pcbpilot-wt/review-kimi`。实测脚本在
> `scratchpad/aesthetics/claude-agent/aesmetrics.py` 和 `extra.py`，原始输出在 `fixed.out.json`、`live.out.json`。
> 结论先说：这块板上最显眼的"丑"不在 A* 的主路径里，而在两类**离网格的直线段**：扇出短线和焊盘引出线。
> 另外，仓库里还没有任何一块"好的已布线"参考板，所以布线美观度目前**没有正样本可以校准**。

## 0. 基线实测（Baseline measurements）

**测试对象**
- `pkg/pcbauto/testdata/esp32-v05-fixed.routed.json`：pcb auto 的计划铜皮，4 层板，信号层为 TOP 和 BOTTOM，共 246 段，总长 11.76 in，82 个连接。
- `esp32-v05-live.reload.json`：同一块板保存并重载后的现场版本。两份结果几乎一致，下文只在有差别时单独说明。
- `internal/app/testdata/boards/*.json` 里的 5 块真板**都没有 copper 字段**，没法拿来做布线对照。

**这组基线说明了什么**
- chamfer/stringPull 已经把"90° 拐角"和"中段歪线"做到 0，主路径本身是干净的。
- 剩下的难看之处按严重程度排：
  1. 扇出和焊盘引出的任意角短线；
  2. 一格宽的 S 形错位；
  3. 离格。
- 这三项都能在 A* 之外用后处理修掉，成本低，收益可以直接量出来。

## 1. 分类体系与可计算指标

每项的得分方式和阈值（阈值待校准）如下，最后一列写与电气目标的冲突及优先级。

**(a) 布局**

| ID | 准则 | 指标 → 0–100 | 冲突与优先级 |
|---|---|---|---|
| P1 | 落格 | 原点落在 5 mil 格的比例（已有） | 无 |
| P2 | 同组朝向一致 | 多数朝向占比（已有），再加上极性件（二极管、电解电容、IC 的 pin1）同向的比例 | 热回路、去耦朝向优先，需要例外清单 |
| P3 | 行列对齐 | 同类件中心的 x 或 y 与 ≥1 个近邻差 ≤0.5 mil 的比例（近邻：3 倍本体尺寸内）。ramp：40%→0 分，90%→100 分 | 去耦就近优先：只有位移 ≤1 倍本体、且回路面积增幅 ≤5% 才算"本可对齐" |
| P4 | 阵列等距 | 行内中心距 CV（已有 pitch 判据）。CV 0.02→100 分，0.15→0 分 | 无 |
| P5 | 同构通道复用一致 | 同构子电路（网拓扑哈希相同）之间做刚体或镜像变换后，相对位置的 RMS 偏差。RMS/本体 0.05→100 分，0.5→0 分 | 无 |
| P6 | 留白均衡 | 板面分格的占用率 CV，只看器件层 | 分区隔离优先 |

**(b) 布线**

| ID | 准则 | 指标 → 0–100 | 冲突与优先级 |
|---|---|---|---|
| R1 | 拐点经济 | 每连接的多余拐点 = 拐点 − 最少必要拐点（端点共 8 向直线时为 0，否则为 1；一个 chamfer 按 1 次计）。ramp：0.3→100 分，2.0→0 分 | 绕长匹配和避让让路。蛇形段标记后从统计里剔除 |
| R2 | 8 向纪律 | 非 8 向长度占比，排除焊盘内部。0%→100 分，3%→0 分。**偏差 <3° 的段按 2 倍计权**（微歪最刺眼） | 无。任意角不带来电气收益 |
| R3 | 无小错位、无锯齿 | 横向偏移 <2 倍线宽的 S 形错位数，加上楼梯段数（≥3 个拐点且中段都 <30 mil），按每英寸计。0→100 分，1/in→0 分 | 无 |
| R4 | 90° 和锐角残留 | 个数。90° 每个扣 10 分，锐角直接 0 分（锐角有酸阱问题，同时算 DRC 类问题） | 无 |
| R5 | 焊盘进入 | 在焊盘坐标系里：轴向记 1，45° 记 0.7，斜入记 0，从角部出线再 −0.5；终点不在中心线上（偏离 >0.1 倍短边）记 0.5。最后取平均 | 去耦回路更短优先：斜入只有在回路面积 −10% 以上时才豁免 |
| R6 | 平行等距、总线梳齐 | 束内间距 CV。0.05→100 分，0.3→0 分。另外"差一点相等"（两个间距差 0.5–2 mil）单独计数 | 3W、串扰和耦合间距由电气决定。美观只要求**满足下限之后**的均匀性 |
| R7 | 层方向 | 只在"非器件层"的信号层上算首选轴占比（BOTTOM 及内层）。60%→0 分，95%→100 分 | 换层会增加过孔、破坏回流路径，所以这项权重最低，不能为它加过孔 |
| R8 | 过孔整齐 | 同一扇出类的"焊盘到过孔距离"CV；过孔落在设计格的比例；相邻过孔共线的比例 | 电流过孔阵列的间距以载流为准 |
| R9 | 线宽和缩颈一致 | 每网线宽种类数；缩颈发生在无障碍处的次数；共线冗余顶点数 | 载流线宽不可降 |
| R10 | 通道居中 | 单线两侧空隙都 >2 倍间距时，偏心度 \|g1−g2\|/(g1+g2) | 高压、爬电下的"贴边"不允许 |
| C1 | 铺铜 | 碎铜（sliver）数、宽度 <2 倍间距的颈部数、孤岛数、热焊盘辐条一致性 | 爬电和板边距离是门禁 |
| S1 | 丝印 | 已有字号和方位判据，再加上文字方向种类 ≤2 | 无 |

**总优先级（全局规则）**
- 门禁（DRC、短路、爬电、板边、载流）优先于电气项，电气项优先于完成率，完成率优先于美观。
- 美观只在"电气代价 ≤ε"的解空间里起作用：长度 +3%、过孔 +0、电气项分数不下降。

## 2. 纳入联合评分

- **分组与权重**：新增 `aesthetics` 组，与现有组一起在 `joint.go` 里做加权几何平均。建议权重：electrical 0.45、efficiency 0.20、placement 0.25、aesthetics 0.10。
  - placement 组里已经包含 layout-score 的 tidy。布线美观度不能再往 placement 里塞，否则同一件事会算两次。
  - 组内用**算术加权平均**，因为组内各项允许互相补偿。组间用几何平均，保证美观不能掩盖电气。
  - 美观组设下限 `max(s,20)`，避免 log 惩罚过重，一项没做好就把整块板打死。
- **防刷分**：
  1. 所有布线指标按"已布连接"归一，同时把**未布连接按 0 分计入**，权重为 1/连接数。这样"少布几根"不可能让分数上升。完成率平方因子保持不变。
  2. 拐点和错位按"每连接的多余量"算，不按总数算，否则会鼓励绕远走直线。R1 与 efficiency 组的 detour 相互制衡。
  3. 美观后处理必须做 A/B 断言：`electrical` 各项、DRC 条数、过孔数不得变差，否则回滚。
  4. 前 3 个版本只报告、不入分（权重 0），等校准通过后再开权重。
- **校准**：
  1. **正样本**：用 5 块 lckfb/bbclaw 真板补采铜皮（`pcb dump --include-copper`，只读采集），各项得分应 ≥75。
  2. **负样本**：在正样本上程序化劣化，比如插 1 格的 S 形错位、把扇出线旋转 5°、把间距扰动 ±2 mil。每个指标必须**单调下降**，接入 `make layout-calibrate` 的格式。
  3. **人工排序**：同一网表用不同 seed、不同参数生成 N 个版本，渲染成局部裁图，做两两偏好（100–200 对）。用 Bradley-Terry 拟合各项权重，留出集上的 Kendall τ 要 ≥0.6。

## 3. 生成：布局

这部分放在 placer 之后做后处理合法化，比放进退火的代价函数更可预期。复用 `placer.tidy` 已有的 `try()`（`hardCost`=0，局部代价 ≤+2~5%）。

1. **对齐线吸附**：同类件中心 x/y 做一维聚类（排序后按容差 ≤0.5 倍本体扫描），吸附到簇的中位数。按簇从大到小逐件 `try`。
2. **阵列等距**：检测 ≥3 个同封装共线件，用最小二乘求等距 pitch（两端锚定），落到 5 mil 格后整行尝试。
3. **同构通道复制**：按"器件类 + 引脚角色 + 邻接"做 WL 哈希，找出同构子电路。选一个 leader，把相对位姿平移或镜像复制给 follower，按整组 `try`。与 docs/concepts 里的"块"数据模型对齐。
4. **旋转折叠加极性统一**：现有 tidy 只处理对称两脚件，要扩展到二极管和 IC 的 pin1 方向。同时加回归测试，查清楚为什么本 fixture 里 R1/R2/R3 仍是 180°。
5. **退火代价**：只加一个很小的对齐吸引项（权重约为 wirelength 的 2%），给后处理留出起点。不建议上 ILP。400 件以内，一维聚类加贪心就够。

## 4. 生成：布线

**A\* 代价（`router.go search`）**
- 保留现有的 90°=2g、45°=0.4g。
- 新增"近距离反向拐"惩罚：本次拐弯与上一次拐弯方向相反、且间隔 <k 格时加 1.5g。这需要在状态里存"上次拐点距离"，用一个 int8 即可。
- 把 `WrongDirCost` 只作用于非器件层。
- 过孔落在设计格给小额奖励。
- **总线场**：把 `buildPairField`（差分对）推广到总线组。在距已布邻线恰好一个 pitch 的格点上给代价折扣，让总线自然并行。

**后处理（按收益 / 成本排序）**
1. **扇出线射线化**：过孔候选只取焊盘中心的 8 条射线，优先焊盘轴向且背离本体。过孔落点可以离格，精确落在射线上，距离取"焊盘半长 + 过孔半径 + 间距"并取整到 1 mil。同一封装类的距离保持一致。
2. **焊盘引出线 8 向化**：把"焊盘中心 → 接入格点"的任意角线改成两段：先沿焊盘轴向，再接 45° 或正交段到格点。`access()` 的候选排序改为"与焊盘轴线的对齐度优先，距离次之"。
3. **小错位消除**：横向偏移 <2 倍线宽的 S 形错位，尝试把其中一段平移到另一段的线上（用 `segmentOK` 校验），迭代到不动点。
4. **共线合并**：线宽不同的子段之间也要做 `compress`，缩颈边界只放在真正的障碍处。
5. **总线梳齐与通道居中**：检测 ≥3 根的平行束，在两侧固定障碍之间一维均分间距；单线则推到通道中线。都要经过 DRC 和电气断言。
6. 泪滴、圆弧拐角作为可选导出样式，只改外观、不改拓扑。

**布线顺序和算法路线**
- 先布 HS/差分/总线，再按连接器引脚顺序做平面排序，减少交叉和绕行。
- 拓扑/橡皮筋布线收益大，但重写成本高，本期不做。"格点 A* + 无格点后处理"是务实路线。

## 5. VLM 渲染评审

- **可以做，但只作离线的副信号，永不入分、不做门禁**，与仓库"截图仅辅助发现、必须转为数据回归"的原则一致。
- **用途**：
  1. 在人工偏好数据之外做廉价的初筛；
  2. 发现新的丑点类别。VLM 给出的每一条批评都要落成几何指标加负例 fixture，才算数。
- **风险**：结果不确定；偏好"稀疏好看"，与完成率相冲突；看不出层和网络；有幻觉；容易被渲染风格左右。
- **保持诚实的做法**：
  - 固定渲染样式和裁图方式；
  - 同一图多次询问，看一致性；
  - A/B 顺序随机、盲评；
  - 与人工两两偏好的一致率要 ≥70%，否则停用；
  - 权重恒为 0。

**附：本次发现的非美观疑点**
- USB_DP/DM 线宽 11.7，但近距离并行只有 22 mil；USB_DM 有 2 段在 BOTTOM，USB_DP 全程在 TOP。建议单独核查差分对规划是否生效。
