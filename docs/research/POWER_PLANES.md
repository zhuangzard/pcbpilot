# 电源脚"短桩+过孔接内层电源平面"实验（PicoRick U303，二丫，direct-fastroute）

日期 2026-10-13。全部数字来自真实运行（fastroute 0.1.13 + pcbnew 导入 + kicad-cli DRC，均在二丫的 agent shell 里直接调用，没有经过 /tmp/pcbpilot-dev）。
标注：**direct-fastroute，无 pcbpilot 的出线桩/加宽步骤，只能与本表内的运行做配对比较**；绝对数不能与 pcbpilot 全流程基线（5 未布通 / DRC 9）直接比。
二丫目录 `~/fpga-remote/pcbpilot-handoff/v093-planes/`；本机记录 `coadapt/records/planes/`（`INDEX.csv`、`runs/<id>/`、`scripts*/`、`geometry/`）。

## 1. 板子事实（读 .kicad_pcb）
- 4 层：F.Cu / In1.Cu(power) / In2.Cu(power) / B.Cu。**In1 与 In2 都已经是整板 GND 铜皮**（zone "Continuous GND return In1.Cu / In2.Cu"，11,11–119,119）。所以"当前空闲的内层"**不存在**；任何电源平面都必须占用 In2（或 In1）的 GND。
- 过孔 0.6/0.3，网类 Power3V3 线宽 0.40005（min 0.254），DSN 间距 0.1551（DRC 规则 0.1501/0.1524）。fastroute 的 DSN 把 In1/In2 导出为 `(plane GND …)`，信号层实际只有 F/B。
- +3V3：约 42 个焊盘（U303 的 1,10,22,33,42,43,44,48,49 + 本地去耦电容 + 全板其它位置），+1V1：6 个焊盘（U303.23/45/50、C306/C307/C308），+1V1 全在 U303 周围 ~14 mm 内。
- U303 = QFN-56 0.4 mm，焊盘 0.875×0.2。右列从上到下：50(1V1) 49(3V3) 48(3V3) 47(USB) 46(USB) 45(1V1) 44(3V3) 43(3V3)——引脚相互交错。

## 2. 方法
1. 精确几何（pcbnew 导出每个铜焊盘的真实多边形，纯 Python 距离）：对每个电源焊盘在 1.2 mm 半径内以 0.02 mm 网格枚举过孔位置，要求过孔(0.6)到所有他网铜 ≥0.1524、10 mil(0.254) 桩到他网铜 ≥0.1524；再对 U303 的 12 个电源脚做联合求解（过孔-过孔、桩-桩、桩-过孔间隙，相邻同网脚可共用 1 个过孔，目标=最少被挡住的信号脚直出）。脚本 `geometry/{viafeas,joint,verify_assign,mkplan}.py`（逻辑沿用 router-sim/exitfeas.py）。
2. 把求出的桩+过孔写进 DSN 的 wiring 作为固定件（`type fix`）；板子里把 In2 的 GND 铜皮改成 +3V3（DSN 随之变成 `(plane +3V3 …)`，In1 仍是 GND 平面）；fastroute 固定参数与 v093-pairs 完全相同（multi-start=1，单线程，确定性）；SES 用 pcbnew 导入；kicad-cli DRC（`--severity-all --refill-zones`）直接在 agent shell 运行。
3. 脚本 `pair_planes.py` / `plane_post.py` 是复制 v093-pairs/pair.py 改的（原件没动）。

## 5. 判断（步骤 3）
- **能让板子布通/降低未布通吗？** 能降低，但要付出"叠层决策"代价：In2 整层 GND → +3V3 平面，且 +1V1 仍要靠固定桩+过孔+普通走线。c6a/c6s：未布通 2/1（基线 13，同一 direct-fastroute 口径），DRC 总数 2/1（其它错误 0），低于人工基线 9。**电源网（+3V3 全网 + +1V1）0 未布通**；剩下的 GPIO11/GPIO17 是非电源网，在基线里是布通的——这类挪动换来换去的现象与 REAL_PAIRED 的"混沌"同量级（σ≈1.6），不能当作规律，也说明本方法没有解决拥塞，只是消除了 U303 电源脚的几何不可能。
- 只"把电源网从轨道布线器移走"(b1)没有用：其余网络布得更差(3 vs 1)。**关键是电源脚要有预置的桩+过孔**：c3b 只给 +3V3 预置，+1V1 的 3 条（45 blocked、50–45 blocked、23–C307）原样未布通；c6a 给 +1V1 的 23/45/50 也预置（过孔放在封装体内侧）后，这 3 条就由路由器布通了。
- (d) 单层切分(+3V3 与 +1V1 同层)：**没找到干净的分割，未证明不可能**。右列 50(1V1)/49,48(3V3)/45(1V1)/44,43(3V3) 交错，1V1 区域要把 50 与 45 连起来就得绕过 48/49 的过孔(只能走 x≈68.0–68.18 一条 0.28 mm 窄带，间距 0.2)，23 与 C307 又要穿过 22、C314 的过孔；Voronoi 切分(c1/c2)导致 +1V1 各块不相通（4 项未连），把 1V1 当 In2 窄线画(c5a)则割碎 +3V3 平面（22 项未连）。所以建议只把 +3V3 做成一整层平面，+1V1 保持短桩+过孔+普通走线。
- 缺口/未覆盖：GND 现在只剩 In1（回流/阻抗/EMI 没评估）；0.127 阻焊间距只靠 KiCad DRC 的 solder_mask_bridge/孔距检查（0 错误），没有独立验证；每个变体只跑 1 次（路由器确定，但输入扰动混沌大）；c1/c2 的 v1 方案未重跑（保留为负/部分结果）。

## 6. 涉及的门禁——不放松任何一条，但有 2 处需要明确解释（读 pourlayer 工作树 `internal/app/pcb_route_gates.go`）
1. **intent-widths**（`checkIntentWidths`）：低于意图宽度的线段只有三种放行：≥net 的 min(10 mil)且在焊盘逃线区内（两端都在自家焊盘铜 max(3×宽,30 mil)=47.25 mil 内、且一端在 50 mil 内），或线段整体在自网铜皮内，或按线段电流判定。我们的桩宽 10 mil = min，长度 ≤0.46 mm(18 mil)，**按现有规则本来就合规，不需要改解释**。+3V3 大面积铜皮不是 track，不受该门禁约束。
2. **route-complete**：fastroute 路径用 `routeCompleteGate`（`UnroutedCount==0 && Fixable==0 && BelowMinWidthNets==0`，来自路由器报告），另有 `boardRouteCompleteGate`（`postsim.CopperConnectivity`：焊盘/线/过孔/**真实面积铜**按精确几何连通）。"电源网由平面连接即满足"对 GND 已经是现行做法；新增的只有：(i) .kicad_pcb 里必须真有 In2 的 +3V3 铜皮，DSN 导出才会出现 `plane +3V3`；(ii) 判定前铜皮必须刷新（我们用 kicad-cli `--refill-zones`），否则 board 连通性看不到平面。这两点是**流程/叠层决策**，不是放松；但"把 In2 的 GND 整层改成 +3V3"会改变用户的叠层，**必须用户批准**，不能自动做。
3. KiCad DRC 0.1524/0.127：所有成功运行的 DRC 错误类别均为 0（clearance/hole/annular/mask 桥）。DSN 余量 0.1551 比 0.1524 大 2.7 µm，建议预置过孔按 0.156 求解（c6s 已验证可行）。
4. pcbpilot 现有 planner：`pcb_intent_escapes.go` 已有 `inward-via` 类型，但 `viaAtSMD` 禁止同网 via-at-SMD、而 fastroute 强制允许；本实验的固定件正是"焊盘端外/封装体内侧的桩+过孔"，要接入需要为 +3V3/+1V1 放宽该开关或增加"power-plane escape"种类（需代码改动，本次未做、未改任何分支）。

## 7. 结论（8 行）
1. 板子的 In1/In2 已经都是整板 GND，不存在空闲内层；电源平面方案必须拿 In2 的 GND 换 +3V3。
2. U303 的 12 个电源脚在 1.2 mm 内都能放合法的 10 mil 桩+过孔（联合解 10 个过孔，间隙≥0.1524，按 0.156 也可行），中间脚在焊盘端外 0.32 mm，23/45/50 在封装体内侧。
3. 单纯把 +3V3/+1V1 从布线器移走(b1)无益：其余网络未布通 3 条（基线 1）。
4. In2 整层 +3V3 平面 + U303 全部电源脚预置桩+过孔（c6a/c6s）：+3V3 全网与 +1V1 全部连通，未布通 2/1（基线 13），DRC 总数 2/1 且其它错误 0，优于人工基线 9；c6a/c6b 完全重复。
5. +1V1 不适合做平面：同层切分没找到干净方案（Voronoi 切分 +1V1 断成 4 块；把 1V1 画成 In2 窄线割碎 +3V3 平面 → 22 项未连）；预置桩+过孔后让路由器布 1V1 普通线即可。
6. 剩下的 GPIO11/GPIO17 未布通是拥塞/混沌，不是电源问题；本方法没有解决拥塞。
7. 门禁不需要放松：10 mil 桩属 intent-widths 的焊盘逃线区；route-complete 需要 +3V3 铜皮存在并刷新；但"In2 GND→+3V3"是叠层决策，需用户批准，GND 回流与阻焊 0.127 的独立验证未做。
8. 失败/保留记录：c3a（后处理 bug）、c1/c2（v1 切分方案）、c5a（负结果）；未改任何分支、未 push/tag、没碰 8765 与兄弟 agent 的目录，/tmp/pico 只读复制。
