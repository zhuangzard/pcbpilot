## 为什么要自研

既有能力（`route-short` 的 L 形短线、`route-critical`、`pkg/pcbrouting` 的单网单层 A*、
Freerouting 外包）覆盖不了整板设计里设计师真正要做的判断：

| 需要的判断 | 既有状态 | pcbauto |
|---|---|---|
| 这条线该多宽 | 按网名分四档（0.25/0.4/0.5 mm） | 按电压/电流：IPC-2221 外层、IPC-2152 内层、换层过孔数 |
| 间距该多大 | 板规则单值 | IPC-2221B 电压表；危险电压域按 IEC 60664/62368 爬电/间隙 |
| 几层板 | 人或需求指定 | 由布线需求、高速接口、RF、BGA、电源轨数推导，并给理由 |
| 地和电源怎么铺 | `power-planes` 固定 15/16 层 | 平面分配、Voronoi 电源分割、外层布不通时升混合层 |
| 器件放哪 | 贴芯片启发式 / 单模块候选 | 电压域分区 + 功能块力导向 + 退火 + 机械约束 |
| 高压怎么隔离 | 无 | 识别域与跨域器件，隔离禁铜带，桥接器件骑跨，开槽建议 |
| 整板布线 | 外包 Freerouting（需自备 Java，丢 keepout） | 内置多层协商布线，网级线宽/间距，缩颈，平面扇出 |
| 高速 | 差分对只建约束 | 贴线布线、蛇形等长、跨分割检测 |

## 第 0 阶段：物理可行性与叠层决策（`feasibility.go`）

正规工程顺序：**机械约束（客户需求） → 物理可行性 → 叠层与过孔工艺 → 布局 → 布线**。放不下时，第 0 阶段直接给出
量化的协商意见（放大到多少 mm、为什么），而不是布了一个小时才发现布不通。

| 计算 | 方法 | 标定 |
|---|---|---|
| 器件占地 | 每面器件外框 + 10 mil 装配间距 ÷ 板面积；未布局时判断单面 / 双面贴装 | — |
| 布线需求 | 每个网络的线长估计 × 1.3 绕行 × (线宽 + 间距) ÷ 标准节距；已布局用曼哈顿最小生成树，未布局用 k·√面积 | k = 0.22（7 块真板实测 0.13–0.28） |
| 每层容量 | (板面积 − 该层焊盘遮挡 − 禁布区 − 通孔) ÷ 节距 × η；2 层板扣 15% 给地铺铜 | η = 0.35（7 块已量产板在各自层数下利用率 ≤66%） |
| BGA 逃逸 | 跨边界通道：第 r 圈以内的信号球必须从第 r 圈的缝隙出去，缝隙数 = 该圈周长 ÷ 球距，每缝可过线数按最小线宽计（球间 / 过孔间），解出所需信号层数；板级规则放不下时改用嘉立创 3.5/3.5 mil BGA 区域规则并列为协商项；仍不行则判定盘中孔 / HDI | — |
| 过孔工艺 | 过孔之间要留出一条布线通道（不是“刚好塞得下的最大过孔”）；板默认过孔不行则选 JLC 可做的 BGA 专用过孔并请板厂确认 | — |
| 参考平面 | 高速差分、射频必须有平面；高速线短于 3000 mil 时 2 层板降为“偏紧”（共面接地，阻抗不受控） | — |
| 方案 | 2 / 4 / 4 混合（顶层/地/信号+电源铺铜/底层，3 层信号）/ 6 / 8 层，利用率 ≤75% 宽裕、≤100% 偏紧、否则不足；选最便宜的宽裕方案 | 7 块真板全部判为可行，RK3568 选中 4 层混合（与原设计一致） |
| 协商 | 布线 / 器件占地 / 高压隔离带（爬电距离 × 板短边）三类缺口，换算成保持长宽比的建议尺寸 | ESP32-S3 板框缩到 55% 时，建议放大到 69×39 mm（原板约 64×36 mm） |

`pcb auto run --place` 先跑第 0 阶段定叠层（`--layers` 未指定时），布局在这个决定内进行；布局后的复核只能加层
（`StackOptions.MinLayers`）。报告第 0 节列出方案表、BGA 逃逸表和协商意见。

## 关键算法与为什么这样选

**占位模型（claim）**：每个铜对象占据“半线宽 + 半间距”范围内的栅格；两网不共格即满足间距。
占位格数取 `ceil(r/g − ½)`，保证“不共格 ⇒ 满足精确间距”（沿坐标轴严格成立）；栅格间距按主导
信号类反推，使其占位半径正好是半格（10/6 mil 规则 → 3.2 mil 栅格），该类线距不浪费。
剩余离散误差由焊盘精确距离校验、真实采样点校验和精确 DRC 修复环兜底。

**拥塞协商（PathFinder）**：首轮允许重叠但计价，之后只重布仍冲突的网，冲突格的历史代价
累积、当前重叠代价指数上升。与 Freerouting 的顺序布线 + 推挤相比，结果与布线顺序无关，
不会因为先到的网占了通道而堵死后到的网。最后严格合法化只拆冲突的连接段并禁止重叠重布；
仍无解的报告未布通，**绝不输出短路**。

**平面优先**：先给平面/铺铜网的每个贴片焊盘打扇出过孔（细间距优先、背离器件本体方向优先），
平面层不参与走线，信号布线看到的是扇出后的真实障碍。扇出堵死信号出线时让路（该焊盘退回
由铺铜连接，由连通仿真复核）。

**铺铜连通仿真**：在栅格上模拟铺铜/平面被异网占位与过孔反焊盘打穿后的连通分量，按
“焊盘/过孔/自身走线”并查，孤岛之间自动补走线。这是把 GND 当“自然会连通”的布线器最常见的
漏洞。

**缩颈**：粗电源线在自己焊盘附近放不下时降为工艺最小线宽进出，离开后恢复；0.4 mm 间距
芯片也能从 1 A 电源网正常出线。

**布局：先核心、后辅助（有经验的工程师就是这么画的）**

1. **认核心**。IC、模块、连接器、光耦/隔离器/隔离电源/变压器/继电器是核心件；其余每个被动件
   都要回答“我为谁服务、服务哪只脚”。归属按确定性从高到低判定（`blocks.go`），每条都写 `Why`：

   | 角色 | 判据 | 拉力 / 自由距离 | 工程理由 |
   |---|---|---|---|
   | 去耦 | 电容一端电源轨、一端地，落到 IC 的同轨电源脚；按芯片电源脚数分摊到具体脚 | 按容值分级：≤220 nF 7/25 mil，≤2.2 µF 5/60，>2.2 µF 2.5/180 | 去耦效果由回路电感决定；小容值管高频，必须离脚最近，大电容是低频储能，放远无妨 |
   | 晶振 / 负载电容 | 晶振归共用时钟网最多的 IC；负载电容跟晶振 | 6/40、5/50 | 时钟环路短、下方不走其他信号 |
   | 功率级 | 由“IC 脚—非电源网—电感焊盘”推断开关节点；电感、续流二极管、开关节点上的器件 | 5/60 | 开关节点面积 = 辐射天线，热回路（输入电容—开关—二极管）要最小 |
   | 端口保护 | 保险丝、TVS/ESD、压敏；归到它挂接的连接器引脚 | 5/100 | 浪涌/静电必须在进入板内走线前被泄放，保护件要在接口和被保护芯片之间、紧贴接口 |
   | 上下拉/偏置 | 电阻一端电源/地、一端信号，落到 IC 引脚 | 2/120 | 靠近引脚但不抢去耦的位置 |
   | 信号串联/滤波 | 与核心共信号网（IC 权重 1，连接器 0.5） | 1.5/160 | 源端串阻靠近驱动端 |
   | 链上器件 | 通过已归属器件间接相连 | 0.8/220 | |
   | 测试点 | 测试点类器件 | 0.6/300 | 只需探针可达，不应抢核心周边位置 |

   **开关电源（`powerstage.go`）**：由“IC 脚—非电源网—电感”找到开关节点，按证据分层判拓扑并标置信度：
   开关节点上有对地二极管 = 异步 Buck、有对非地网二极管 = 异步 Boost（`certain`）；同一芯片挂多个电感
   = PMIC/多路 Buck；电感另一端是 VBAT/VIN/VBUS/VSYS 类输入名 = 同步 Boost；否则按常见情况判为同步 Buck
   （`likely`）。输入轨取封装内离 SW 脚最近的最高压电源脚（芯片厂把 VINx 紧贴 LXx，PMIC 每路各一；
   这是封装内相对距离，与摆放无关）。**热回路电容**：Buck 取输入侧、Boost 取输出侧最小的陶瓷电容，
   每路独立；另识别自举电容（SW↔BST）与反馈分压（FB 脚一端到本路输出、一端到地，含前馈电容）。
   布局代价：热回路按焊盘中心多边形计 `3·max(0, 周长−150 mil) + 2·√面积`；反馈件距电感本体或开关
   节点焊盘不足 150 mil 时按差额计罚。**每只电源脚上容值最小的那颗按高频去耦对待**（哪怕它是唯一的
   4.7 µF），其余再按容值分级。

   **接口信号链（`chains.go`）**：从每个连接器 / 天线 / 射频座的信号脚出发，按原理图顺序走到它服务的
   芯片脚：并联件（ESD/TVS、滤波电容）挂在当前网上，串联件（串阻、AC 耦合电容、共模电感按封装内
   “正对面”焊盘找出口）把链带到下一网。到达芯片脚即终止，其余串联件是支路（跳线选项、第二天线）；
   链遇到开关节点或转换器器件即终止；超过 8 个焊盘的网视为总线或未识别的电源轨。代价：主干
   （连接器 → 各串联件 → 芯片）相对直线的折返 + 每个并联件离主干的支线长度 + 保护件沿主干离连接器
   的距离；天线 / 射频座链计**全长**（馈线长度本身就是损耗和失谐），且把链上的网标成 RF 角色交给布线器。
   差分对两侧同一级器件并排。倒置判据：原理图排在保护件之后的串联件，反而比保护件更靠近连接器。
   **端口预留区**：带保护件的连接器，受保护引脚那条边外侧留出一块区域（引脚范围 × 最大成员尺寸 +
   两倍间距），其他块的器件进入按重叠面积计罚，同面生效（RK3568 上 Buck 电感、麦克风滤波电容曾挤掉
   HDMI 的 ESD 位置）。**天线**是核心件（类别 `antenna`），与射频芯片之间的块间拉力 ×4；只共享电源轨的
   块间链路权重降为 0.4（电源由平面供电，共用电源网不代表应该相邻）。
   **精修**：退火后，对热回路、自举、高频去耦、晶振、保护、反馈器件按优先级逐个在目标焊盘 ±180 mil、
   15 mil 网格、四个朝向内穷举，只接受无重叠且代价下降的位置。热回路器件在回路可追踪时只用回路代价，
   不再叠加拴点（两者冲突时，拴点曾经阻止了能缩小回路的 180° 翻转）。

2. **定核心**。功能块宏观力导向：块间弹簧按共享网数加权，时钟/USB/差分/射频链路加倍；连接器与
   机械件固定为锚点；**开关电源块与模拟/射频块之间加 400 mil 排斥**（开关节点的近场耦合）。
   然后逐个核心试 0/90/180/270°，选“每条链路的网所在焊盘离对端块最近”的朝向，出线不绕本体。
3. **贴辅助**。按角色强弱排队（去耦 → 晶振 → 负载 → 功率级 → 保护 → 上下拉 → 串联 → 链 → 测试），
   同角色内容值小的先占位；贴在目标脚所在的那条边外侧，沿边滑动、再向外一排，不与已贴件重叠；
   两脚器件转向使连接脚朝内。**辅助件与核心不在同一面时（BGA 背面去耦），直接放到目标焊盘正下方**，
   只与同面件避让——RK3568/K230 人工板 101/189、144/192 个电容在背面，正是这种做法。
4. **优化**。退火代价 = 加权半周长（地 0、电源 0.15、时钟/RF 4、差分 2.5、开关节点 3）+ 按角色的
   拴点距离 + 保持距离 + 重叠 + 出板/出区 + 禁布 + 限高。移动类型含平移、旋转、同尺寸交换，
   以及**整块刚性移动**（核心带着它的辅助件一起动，块不会被拆散）。冷却进度取“步数/时间”较大者，
   超时也会以低温贪心结束（修正前大板在 90 s 截断时仍处于高温，线长显著变差）。末段合法化螺旋
   搜索四个朝向，最后整齐化（对称被动件朝向归并、组内朝向一致、5 mil 网格）。
5. **可审查**。`report.md` 的“布局依据”表列出每个核心的辅助件、角色和目标引脚；归属错了先修
   原理图/网名或 `blocks.go` 判据，而不是手工挪器件。

## 综合评分与布局↔布线闭环

**为什么要综合**：布局分只是对“布好线的板子”的预测，不能独立作为验收依据。2026-09-23 的实测证明了这一点：MIPI
引擎布局的布局分 70（人工 65.5），布通率却只有 70.7%（人工 100%）。所以验收以布线后的结果为准：

```
综合分 = 门槛 × 布通系数 × 质量分
门槛      短路 / 器件重叠（layout-lint 焊盘并集口径）→ 不可交付，封顶 40
布通系数  (布通率/100)² × 0.97^DRC        # 最后 5% 飞线往往占掉一半人工时间，所以取平方
质量分    三组加权几何平均（任一组差都拉不回来）
  电气 45%  布线后在真实铜皮上测：热回路路径、去耦回路（电源路径 + 地回流）、ESD 支线、
            射频馈线、高速网发现项。距离沿布线图走（Dijkstra），平面段 ×0.25（平面扩散电感远低于走线）
  效率 25%  布线长度 / 焊盘欧氏最小生成树（只算完全布通的网；45° 走线比曼哈顿距离短）、每连接过孔数
  布局 30%  布线看不到的部分：layout-score 的整齐度 / 紧凑 / 接口在板边 / 分区 / 装配间距 / 信号流
```

`pcbpilot pcb auto run --place` 默认跑 3 轮闭环（`--loops`）：布局 → 布线 → 综合分；在未布通焊盘和 DRC 违规点
150 mil 以内的器件加宽半条布线通道（上限 60 mil），然后重新布局；全部布通且 DRC 为零即停止，取综合分最高的一轮。
`report.md` 的“综合评分”一节列出每项的实测值和每一轮的记录。

**第一次实测暴露的根因**：失败不是全局拥挤（RUDY 显示 MIPI 最大利用率只有 0.4），而是**局部的引脚出线**。旧的默认
器件间距 12 mil，而 6/6 规则下过一根线需要 18 mil，被围在中间的焊盘只能绕外围出线。修正：默认间距 = 一条布线
通道（线宽 + 2×间距）；**亲密对**（热回路、去耦、晶振、功率级器件与它们的芯片）保持 12 mil，因为它们之间不需要
外部走线穿过；焊盘上挂着更宽网络的器件，额外加半个线宽差的留空。MIPI 布通率 70.7% → 100%，热回路 390 → 319 mil。

**RUDY 拥塞项**（`rudy.go`）：每个网络的半周长均摊到它的包围盒，每个焊盘另加出线占用，与每格容量（信号层 × 格宽 /
节距）比较，利用率超过 0.8 的部分按线性加平方计罚；退火中增量更新，已用测试验证与从头重算一致。它负责全局拥塞
（RK3568 人工布局最大利用率 2.35，确实布不通），局部出线由间距规则和闭环负责。

### BGA 扇出（`bga.go`，进行中）

**规则单位先修**：以 mil 为显示单位的工程（立创 RK3568/K230），EasyEDA 返回的规则值本身就是 mil，旧解析器
一律 ×39.37，引擎再把离谱的值丢弃、改用 6/6/24 默认值。0.65 mm 球距下 24 mil 过孔离球只剩 0.6 mil，
狗骨头根本放不下；真实规则是 4 mil 间距、0.15/0.25 mm 过孔，离球有 7.6 mil。修正后（值 > 1.5 即为 mil；
快照里多换算了一次的值自动还原）K230 人工布局布通 40.5% → 47.8%，DRC 9 → 1。

**狗骨头规则**：检测 BGA（≥36 个相同的小贴片焊盘、规则阵列、按最近邻距离众数得球距）；最外圈加上两球间能
过的线数圈 `k = ⌊(pitch − ball − clr)/(track + clr)⌋` 在表层直接逃逸；更深的信号球和所有平面球打狗骨头，
位置不假定，而是在朝外半平面里找“到其他球的间隙最大、合法、短桩”的格点（方阵上即四格中心，交错阵列上即
三角中心），由内向外逐圈处理。信号球的狗骨头过孔成为它在每一层的接入节点，布线器从过孔出发逃逸。

**两个教训**：
1. 表层逃逸圈里的平面球，过孔要**朝内**打，否则会占用信号的表层逃逸通道。
2. BGA 平面球的扇出必须**钉住、永不让路**。通用扇出在“信号被扇出过孔挡住”时会让路，但让路后在焊盘外靠铺铜
   补线兜底；球阵中间没有兜底路径，合成板上 37 个 GND 球因此断开。钉住后 GND 失败降到 0。
（平面层连通性也改为按精确反焊盘半径判断，不再用离散化后的占用格；在这次问题里不是主因，但更符合物理实际。）
3. **BGA 过孔规格**：按实测空隙（交错阵列也适用）算能容纳的最大过孔；板子默认过孔放不下就选 JLC 可制造的
   最大过孔（钻孔 ≥0.15 mm，环宽 ≥0.05 mm）并写进报告请设计者与板厂确认，工艺最小值也放不下则判定需要盘中孔。
   RK3568 U4（13.8 mil 球）自动选 9.9/13.9 mil；K230 默认 0.15/0.25 mm 即可。

**现状（默认关闭，`RouteOptions.BGA` 打开）**：6 层合成板 56.1% → 71.2%。真板（人工布局，真实规则，3 min）：
K230 平面连接失败 153 → 60，但信号布通率 50.2% → 43.1%，失败全是超时——钉住的狗骨头不让路，协商轮次变多，
时间不够；RK3568 41.2% → 39.8%。叠层升级路径上，电源改成铺铜后超时跳过了连通仿真，出现 548/549 平面失败
（R-0 同类的超时路径缺陷）。打开为默认之前要解决：超时路径、布线速度、每个球都分到空隙（全局分配代替贪心）。

## EasyEDA API 限制与对策

| 限制 | 影响 | 对策 |
|---|---|---|
| `autoRouting()` 需 ≥3.2.150，本地版本不可用 | 无原生自动布线 | 自研引擎离线求解，只用基础 typed action 落地 |
| 无批量写铜；每段一次 `line.create` | 千段级写入慢 | 剧本可断点续跑（`apply --resume`）；路线图 R-2 用 SES/JSON 一次导入 |
| `getDsnFile` 丢 keepout（#29 wontfix） | 外部布线器会压天线 | 引擎直接读 `pcb dump` 的 region，禁布区进入占位栅格 |
| 无盲埋孔、无弧线创建、无泪滴 | 限制 HDI 与美化 | 只用通孔；倒角用 45° 段；泪滴保持 `unsupported` |
| 新异网过孔不自动挖 PLANE 反焊盘（#32） | 平面短路风险 | 剧本先以信号层铺铜再翻转内电层，最后 `pour.rebuild` |
| 写后回读可能过早（P-01） | 无法判断落地 | 剧本末尾 save → 由用户 reload 后 DRC/check 回读 |

## 路线图（设计者视角补充的需求）

已实现能力之外，作为有经验的 PCB 设计者，整板自动化还应具备以下能力。按对成品质量的影响排序：

**安规与可靠性**
- R-10 完整安规计算：按标准（IEC 62368-1 / 60335-1 / 61010-1）、污染等级、材料组、海拔、
  过电压类别查表；自动生成隔离开槽（`pcb slot`）；市电入口“保险丝 → 压敏 → 共模电感 → 整流”
  拓扑顺序与间距检查；Y 电容跨隔离带位置检查；高压区丝印警示。
- R-11 热设计：按功耗估算热点，发热件远离电解电容/晶振/传感器，自动铺散热铜与 EPAD 热过孔阵列，
  铜厚（1/2 oz）建议。
- R-12 ESD/浪涌拓扑：接口 → 保护器件 → 芯片的顺序与距离约束（保护器件紧贴接口、先经保护再分支）。

**电源完整性**
- R-20 IR 压降仿真：对铺铜/平面做电阻网格求解，检查末端电压，自动加宽瓶颈与增加过孔。
- R-21 去耦网络设计：按芯片电源脚与目标阻抗选容值组合，小容值最近、同层放置、过孔紧贴焊盘。
- R-22 开关电源布局模板：输入电容—开关管—续流环路面积最小，SW 节点铜面积最小并远离敏感信号，
  反馈走线从输出电容取样；以样例驱动方式沉淀为可复用模板。

**信号完整性 / EMC**
- R-30 换层回流：高速信号换层时自动在旁加 GND 回流过孔；跨分割处自动加缝合电容。
- R-31 板边 GND 缝合过孔栅栏、晶振保护环、20H 电源平面内缩、3W 间距（差分对内除外）。
- R-32 串扰估计：平行长度 × 间距 → 自动加大间距或换层。
- R-33 阻抗与工厂叠层对账：接入嘉立创叠层库与阻抗计算，输出制造阻抗要求说明。
- R-34 模拟/数字分区与单点接地（AGND/DGND 星形点位置）。

**可制造 / 可装配 / 可测试**
- R-40 工厂能力库驱动规则（嘉立创各工艺档），写入 EasyEDA 原生网络类与规则，使原生 DRC 与引擎一致。
- R-41 贴装方向统一（极性器件同向）、返修间距、器件离板边距离、工艺边与 Mark 点、拼板。
- R-42 测试点自动放置（关键网/全网，针床间距约束），飞针与 ICT 两种策略。
- R-43 单面贴装优先以降低成本；双面时重/高器件在顶面。

**流程**
- R-0 最终 DRC 闸门覆盖扇出过孔与板边，超时路径也保证零违规（见上方已知缺陷）。
- R-1 与 Freerouting 同 DSN 正面对比基准（布通率、过孔、线长、耗时、DRC）。
- R-2 SES/JSON 一次性导入路径（DSN 解析 + SES 生成），替代逐段写入。
- R-3 多方案对比：层数 × 面积 × 工艺成本 与 布通率/过孔/SI 指标并列，供人决策。
- R-4 ECO 增量：原理图改动后只重排重布受影响部分，保留已确认布局布线。
- R-5 外壳约束：STEP 外壳导入，按键/LED/屏幕/接口与面板开孔对齐，限高区自动生成。
- R-6 BGA 逃逸（狗骨扇出、via-in-pad 选项）与 6 层以上内层走线方向规划。
- R-7 密集板容量：扇出过孔与信号协同协商（扇出可移位而非只可删除）、混合层上的电源铺铜与
  信号共同优化、按连接方向分配层（而非固定 h/v）、布局阶段引入 RUDY 拥塞估计回灌。
