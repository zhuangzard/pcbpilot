# ADR 0005: 将初级 PCB 训练材料沉淀为脱敏能力基准

## Status

Superseded in part. (2026-09-10) — 仍禁止公开原题内容；“所有黄金数据必须私有”的决定由
本 ADR 第 6 节修订，允许将独立提炼、脱敏、不可反推原题的复用模块数据公开维护。

## Context

一组外部训练材料包含多份 BOM、参考原理图、操作要求和评分说明。材料覆盖了
初级两层板从工程准备到最终检查的完整链路，适合作为 easyeda-agent 的能力基准，
但原始材料包含不应复制到公开仓库的题目名称、指定参数、器件清单、坐标、图形和
评分细节。

因此，仓库只沉淀从材料归纳出的**能力类别、风险模式和验收方法**。原始附件留在
用户本地，既不复制进仓库，也不在 ADR 中建立可反推出原题的逐项映射。后续实现者
需要原始数值或拓扑时，必须由用户再次提供或在获准的本地路径读取。

材料揭示的通用工作负载是：依据参考图和 BOM 复刻原理图，再将其同步至 PCB，完成
规则设置、约束布局、两层布线、铜皮/过孔处理、标注与 DRC。这里的关键不是推导新
电路，而是高保真、可核验地重建既定设计意图。

## Decision

### 1. 以脱敏能力分类保存材料价值

将训练材料抽象成以下能力域，作为后续 roadmap、E2E 和回归用例的输入：

| 能力域 | 必须覆盖的通用行为 | 验收证据 |
|---|---|---|
| 工程准备 | 目标工程/页面确认、命名、保存纪律 | 回读工程与文档上下文，显式 save |
| BOM 驱动放置 | 以供应商标识确定性解析器件，保留位号、值和封装身份 | 器件表与 BOM 对账，无模糊替代 |
| 原理图复刻 | 按模块放置，重建 wire、网络标记、NC、属性和说明 | pin-to-net/NC 黄金表逐脚一致 |
| 原理图质量 | 分区、模块框、文字说明、可读布局 | `sch gate --strict` 与跨页网络检查通过 |
| 专用库图形 | 复用或重绑已准备好的自定义符号/封装 | 库身份回读，重绑后重新核对连线 |
| PCB 规则 | 间距、普通/电源线宽、过孔和网络类 | live 规则回读；不可写项标为人工门 |
| 机械约束 | 板框、圆角、孔、边缘接口、坐标、角度和锁定 | 几何/锁定状态回读，器件不出板 |
| 布局意图 | 电源回路、去耦顺序、晶振、接口、传感器/RF 可用性 | layout-lint/score + 逐器件归因 |
| 布线意图 | 两层、宽线电源、短直敏感网、层限制、过孔预算 | 网络/图层/线宽/过孔统计与 `pcb check` |
| 铜与回流 | GND 铜皮、缝合过孔、局部净空或机械开槽 | pour/via/region/slot 回读及 DRC |
| 标注与收尾 | 功能丝印、位号整理、方向和可制造尺寸 | 丝印碰撞检查、保存、DRC=0 |

### 2. 不在 ADR 中保存原题可识别信息

以下数据不得进入本 ADR、公开示例、fixture 名称、提交信息或日志样例：

- 原题/工程名称、客户或考试标识；
- 原始 BOM 行、供应商料号和完整器件组合；
- 指定板框尺寸、器件坐标、角度或评分分值；
- 原理图截图、逐网拓扑、题目专用文字；
- 足以将多个脱敏字段重新拼回某一原题的映射表。

允许保存的是能力类别、是否可自动化、平台限制、通用验收方法和匿名化统计。

### 3. 复现采用“参考设计复制”而非“新方案设计”流程

训练复现必须先从本地参考材料生成临时、非提交的黄金数据：

1. BOM 身份表：位号、器件类别、值、封装、确定性库身份；
2. pin-to-net/NC 黄金表；
3. 页面模块与视觉相对关系；
4. 自定义符号/封装人工门清单；
5. PCB 阶段约束清单。

黄金数据只存放于被 `.gitignore` 覆盖的临时目录或用户指定的私有位置。原理图完成
后以逐脚拓扑对账为主判据，参考图视觉相似度仅作为布局辅助，不能替代电气验证。

### 4. 能力边界必须显式分成三类

后续读取本 ADR 的实现者不得把“能画出结果”混同为“能写入编辑器设置”：

- **自动化**：已有 typed action，且能够写后回读验证；
- **受控降级**：可以生成等效几何或结果，但不能证明编辑器内部设置项一致；
- **人工门**：缺少 typed API，必须由用户在 EasyEDA UI 完成并由 agent 回读可见结果。

当前人工门主要包括：完整 PCB 规则管理器写入、用户坐标原点、原生泪滴、字体族、
符号内部图元编辑和封装内部图元换层。若未来 typed action 覆盖这些能力，应更新本
ADR 的状态或增加后继 ADR，而不是静默宣称全自动。

### 5. 建立一个匿名基准复现用例

从材料中选择规模较小但能力覆盖完整的一份，建立匿名基准名
`training-schematic-baseline-a`。首轮范围只到原理图 S6：

- 从空白、独立训练工程开始；
- 按参考 BOM 和拓扑放置、分区、布线；
- 自定义符号若尚未准备好，记录人工门并使用电气等价库符号完成拓扑验证；
- 逐页通过 `sch gate --strict`、全工程网络检查和黄金表对账；
- 显式保存并导出原理图图像、BOM、网表及审计摘要；
- 不在仓库提交产物中出现原题可识别信息。

PCB Layout 作为后续教学阶段处理，不把自动布线结果冒充为学习过程。布局与布线应
提供逐阶段证据，使学员能观察电源回路、去耦、晶振、接口、RF/传感器以及回流路径
等通用原则。

## Consequences

- 训练材料可以持续影响产品能力和测试覆盖，同时避免把原题复制进公开仓库；
- 后续 agent 有稳定的能力地图、验收口径和人工门，不必重复进行整套资料分析；
- 原始参数不会随仓库分发，实际复现仍依赖获准访问的本地材料；
- 高保真原理图复现必须多一道黄金拓扑生成和对账，速度略慢，但能避免“截图相似、
  电气错误”；
- 任何公开 E2E fixture 必须重新设计成电气等价但不可反推原题的合成案例。

### 6. 公开维护脱敏复用模块（2026-09-10 修订）

允许在 `.agents/skills/pcbpilot/library/modules/` 公共维护从多份材料归纳出的功能模块记录，
条件是：不记录材料路径、题名、逐题映射、完整 BOM、整板拓扑、指定坐标、评分文本或原始图形；
来源只保存聚合类别和独立可验证依据。数据按 `draft → topology_ready → compose_ready` 晋级，
缺库身份、逐脚连接或实测几何时必须停留在较低成熟度。

Block Template 与公共 Lib Module 分工：前者是参数化拓扑配方，后者是实例级连接与几何资产。
已有 Block 的功能由 Lib 记录引用，不复制一份易漂移的拓扑；只有通用、可参数化且边界端口稳定的
候选才贡献为新 Block。公开复用数据仍不得拼回任何一套原题，完整复现黄金表继续不提交。
