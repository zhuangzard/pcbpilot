# pcbpilot v0.9.1 交接报告（2026-10-09）

另一台机器从这里接着做。本文写明：当前状态、各分支、正在进行的工作、新机器怎么搭环境、下一步做什么。

## 1. 用户的硬性要求（不能丢）

- 回复用中文；自主推进，不反复提问；推送或发布前先问（用户已授权 v0.9.x 发布和 push public）。
- **KiCad 是主设计工具**，零件仍用嘉立创 LCSC 料号；EasyEDA 只用来最后导入和下单。
- **核心卖点全部是硬 gate，每个后端都要有**（EasyEDA、KiCad，以及以后新增的任何后端）：
  - Codex / Kimi / Claude 三方设计审核（`pcbpilot review-panel`）；
  - 元器件安全：LCSC 料号，以及 IEC 60601-1 MOOP/MOPP、60664、62368、61010、IPC-2221B 的爬电距离、电气间隙、板边距离；
  - 线宽按每一段的电流定，加过孔阵列、压降（IR），规定不能变细的地方不能变细；
  - 原理图到 PCB 连贯：网表一致，并出追溯表；
  - 布线后仿真、说明书（含仿真章节）、最终设计报告。
- 原理图要像资深工程师画的：信号从左到右、电源在上地在下、去耦电容贴着芯片、跨区网络用标签、按功能分页、图框齐全。**AI 不写坐标。**
- 允许学习其他工具的原理（读源码，或用 REA 逆向，github.com/morluto/rea），学完自己写，不复制代码。
- fastroute 每 3 天检查一次新版本（`scripts/fastroute-upgrade-check.sh`）；TraceMaker 也要跟进。
- 编译和测试都用 `nice -n 19`。

## 4. 进行中（交接时还没完成）

1. **kicad/sch-build 第二轮观感修正**（worktree `pcbpilot-wt/kicad-sch-build`），要做：
   - 页面密度：内容至少占 40%，选最小能放下的纸张；
   - 文字、符号、标签两两不重叠（≥0.25 mm，用真实字体尺寸）；
   - 接插件和外部输入放在页面左侧；
   - PWR_FLAG 放在电源入口附近；
   - CH340C 的去耦电容紧贴芯片；
   - 渲染 PNG 后交给 review-panel 做看图审核。
   - 渲染方法：`"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --window-size=2000,1414 --screenshot=out.png file://<page>.svg`
   - 当前 ESP32-mini：31 个元件、22 个网络，缓存命中时 4–7 秒，所有 gate 都通过；但图上还有上面这些问题。
2. **kicad/escape-stubs**（worktree `pcbpilot-wt/kicad-escape-stubs`）：给细间距焊盘预放"出口短线"，作为固定走线交给 fastroute。原因是意图网络禁止缩细后，PicoRick 剩 11 条线布不通（RP2040 U303 的 +3V3/+1V1/VREF 和 IC102 的 5V）。intent-widths gate 只接受焊盘附近 max(3w, 30 mil) 以内的出口段变细。
3. **TraceMaker 修改版**：`~/Github_Working/tracemaker-pcbpilot`（本地 git，**没有远端**），上游是 v0.9.0。
   - 已完成：线宽约束、禁止缩细、`--constraints`、`--pairs`、报告扩充、回加宽；最新提交 eeb87f3 改为只在焊盘出口缩线、优先级只决定顺序、确定布不通就提前停。
   - 目标：PicoRick 0 条未布通、0 处线宽错误、≤90 秒，并和 fastroute 公平对比。
   - 达标后接成 `kicad route` 的第二个后端，和 fastroute 同时跑，两份结果都过全量 gate，留更好的那份。
   - 编译：`cmake --preset macos-metal && cmake --build --preset macos-metal`；brew 依赖 ninja、cli11、nlohmann-json、catch2。

## 5. 新机器搭环境

```bash
git clone https://github.com/zhuangzard/pcbpilot && cd pcbpilot && git checkout dev
# KiCad 10.0.7（官方 dmg，用 ditto 安装，不要直接覆盖旧版本）
nice -n 19 make test
scripts/fastroute-upgrade-check.sh   # 安装最新 fastroute 到 ~/.pcbpilot/fastroute/current
```

- 审核用的 CLI 要先登录：`codex`、`kimi`、`claude`。
- TraceMaker 修改版：从 bundle 恢复，`git clone tracemaker-pcbpilot.bundle`，再按第 4 节编译。
- 进行中的分支已推到 origin（`kicad/*`），worktree 目录名和分支名一致。
