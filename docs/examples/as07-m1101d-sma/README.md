# AS07-M1101D-SMA 私有库实战

本例记录一次 EasyEDA Pro 个人库创建和交互修正。运行环境为 CLI / daemon / Connector
v1.5.1、EasyEDA Pro 3.2.186。公开附件已去除个人库、工程和图元 UUID。

## 用户需求

根据下图创建 AS07-M1101D-SMA 私有器件库：28 × 15 mm 模块、SMA 接口、2 × 4 排针，
间距 2.54 mm。原理图符号保持图中的左右排列；封装加引脚名与型号丝印，全部放到外框外，
使模块安装后仍能看到，文字排列紧凑整齐。最终确认：全部引脚使用普通线和未定义类型，
去掉 SCK 的时钟箭头；GND 1 脚使用独立圆形定位标记，保留用户已清理 NC 的状态。

![用户提供的模块尺寸与引脚图](mechanical-pin-drawing.png)

图中给出引脚名称，没有标注数字脚号。本例采用逐行从左到右的 1–8 编号，符号与封装
共用此映射，不将其表述为厂家脚号。

| 排（从上到下） | 左列：本例脚号 / 名称 | 右列：本例脚号 / 名称 |
|---|---|---|
| 1 | 1 / GND | 2 / VCC |
| 2 | 3 / GDO0 | 4 / CSN |
| 3 | 5 / SCK | 6 / MOSI |
| 4 | 7 / MISO/GDO1 | 8 / GDO2 |

## 最终结果

已在个人库创建 `EA_AGENT__AS07_M1101D_SMA`，绑定同名符号与
`EA_AGENT__MODULE_AS07_M1101D_SMA` 封装；后续修正保留原有器件绑定。

![官方符号渲染图](symbol.png)

![官方封装缩略图：框外引脚标签与型号](footprint.png)

封装图是官方接口返回的缩略图，细节核对以原始几何与文字包围盒为准。

- 8 个通孔焊盘，直径约 1.70 mm、孔径约 1.00 mm，1 号为方形焊盘。
- 符号矩形闭合，左右引脚朝向正确，名称在框内；顺序与用户图一致。
- GND 1 号脚旁使用独立圆形定位标记；CSN 4 号脚不画反相圆圈，避免与定位标记混淆。
  所有引脚使用普通线形（`None`）和未定义电气类型（`Undefined`），5 号脚不画时钟箭头。
  用户已删除影响实际接线的 NC 标记；后续修改保留该状态，最终官方渲染图确认不再显示叉号。
  此前仅凭 `noConnected:false` 将叉号解释为连接点的判断错误，不能作为 NC 验收依据。
- 封装引脚文字位于左侧外框之外，奇偶两列、同行对齐，带脚号消除对应歧义。
  两列均右对齐，列间距 20 mil（0.508 mm），靠框列距轮廓中心线 25 mil（0.635 mm）。
- 型号位于上边框外并居中；文字下沿距轮廓中心线 20 mil（0.508 mm）。
- 已回读 9 段可见文字包围盒，验证全部位于模块覆盖区域外、相互无重叠，显式保存成功。

## 可追溯附件与执行范围

| 附件 | 用途 |
|---|---|
| [device.json](device.json) | 最终符号和封装几何、证据与尺寸假设；使用前替换个人库 UUID 占位符 |
| [silkscreen.json](silkscreen.json) | 最终 8 个引脚标签和型号的位置、字号及对齐参数，单位 mil |
| [verification.json](verification.json) | 现场符号与焊盘回读、最终丝印包围盒及保存结果，移除了私有标识 |

初始资产通过 `pcbpilot lib device validate` 与 `lib device build` 创建；随后通过官方
`eda.*` API 调试路径修正既有符号、添加和整理封装文字，再保存并回读。
`device.json` 已同步最终符号几何；`silkscreen.json` 是独立的补充规格，当前
`lib device build` 不会自动消费它。因此本例证明的是 Agent 完成建库和修正的实际结果，
不是单条 build 命令已覆盖全部丝印需求。

初版存在未闭合边框、引脚朝外和按功能重排的问题。用户指出后进行了修正，官方渲染图
确认符号效果；最终丝印又按“框外可见、紧凑整齐”的要求调整。编号校验或资产创建的
`verified:true` 本身不能证明图形正确。

## 已验证与未验证

已完成资产创建与绑定回读、8 pin ↔ 8 pad 编号校验、符号图形复核、封装焊盘坐标回读、
丝印包围盒检查及显式保存。丝印位置不改变焊盘几何。

输入图不等于完整原厂数据手册，厂家身份尚未确认。焊盘直径、孔径采用常见 2.54 mm 排针
的计算假设；图中未明确标注的排针至模块边缘偏移按 1.27 mm 推算。这不是厂家推荐 land
pattern。图片中的模块自身安装孔未作为主板钻孔加入本例。

用户反馈曾在实际实例中遇到 NC 导致无法接线，并自行清理；此后本次 Agent 未再次执行
实例放置与实际接线验证。尚未完成 PCB DRC、实物尺寸与装配验证，也未创建 3D 模型；因此不声明
生产就绪、机械全尺寸还原或整板端到端验收通过。
